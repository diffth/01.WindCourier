# 산맥 바람 안개 — 2026-09-27

장거리 노선의 굵은 파란 직선 띠(`RidgePlume`)를 반투명 안개로 교체했다. 후속 사용자 요청으로 회색 기운을 줄인 청색으로 바꾸고 길이와 폭을 각각 1.5배 확대했다.

- 고개 양옆 네 구역에 기본 18개 조각을 배치한다. 처음 생성할 때 지형을 아래로 추적해 발생 높이를 정한다. 고개 안쪽의 기존 근거리 선도 연한 안개 10개로 교체했다. 안쪽 안개는 1.2km 이내에서만 서서히 나타나며 능선 안개보다 옅게 표시한다.
- 조각마다 길이·폭·생성 위상이 다르다. 바람 방향으로 이동하면서 늘어나고, 가장자리와 내부 농도가 천천히 변한다. 생성과 소멸은 부드럽게 처리해 반복 위치로 돌아갈 때 튀지 않게 한다.
- 강풍에서는 속도와 길이가 증가한다. 멀리서는 3.3~4.5km 구간에서 서서히 사라진다.
- 정면에서 접근해도 평면의 모서리만 보이지 않도록 시점에 맞춰 폭을 가진 안개 덩어리로 표시한다. 지형 접점은 깊이 감쇠로 흐리게 한다.

재질은 `/Game/FlightTest/Materials/M_RidgeMist`, 재생성 스크립트는 `Scripts/update_ridge_mist.py`다. 기존 바람의 힘·방향·범위는 유지한다. 바람 방향 전환 예고에 쓰던 긴 선 34개도 같은 재질의 안개 18개로 교체했다. 예고 시작·종료와 조각 반복 시 투명도를 조절한다. 바람을 그리는 `DrawDebugLine`은 모두 제거했다.

검증: Editor Development 빌드와 `WindCourier.Flight.Weather`, `WindCourier.Flight.WindZone` 자동 테스트 모두 성공. 화면 밖 시뮬레이션에서 산맥 안개 메시 28개 생성 및 원거리·근거리 렌더링 확인. 기존 구름에 일부 가려질 수 있으므로 실제 장거리 비행에서 사전 발견 거리와 움직임의 자연스러움은 후속 플레이로 평가한다.
