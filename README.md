## 문서 관리 원칙

현재 편집 대상은 `GDD/docs/`다. 소개는 짧게 반복할 수 있지만 상세 규칙과 수치는 담당 문서에서만 관리하고 다른 문서는 링크한다. 파일명에는 버전을 붙이지 않고 변경 이력은 Git으로 추적한다.

모든 설계는 초안이며 수치는 실측 전 가설이다. 서로 충돌하는 안은 미결 사항에 남겼으며, 이번 정리만으로 채택하거나 폐기하지 않았다. 보관본은 수정하지 않는다.
