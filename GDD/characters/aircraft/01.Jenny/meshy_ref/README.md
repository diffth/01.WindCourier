# Jenny — Meshy 재생성용 참고 그림 (2026-09-30)

사용자 결정(2번): 원래 디자인(컨셉 `01.Jenny_03_*.png`)을 유지하고 비율만 고친 모델을 **Meshy**로 다시 만든다. 상업 출시판의 3D 모델은 Meshy 결과물이어야 한다(ZR R9·R10). 실측 스크립트 모델에 컨셉 겉모습을 입힌 3번은 "표면이 단조롭고, 형태·색이 다르고, 가늘고 작아 보인다"로 채택하지 않았다.

## 왜 그림을 고쳤나

컨셉 그림끼리 비율이 맞지 않았다. 옆면(`LS`, 길이 ÷ 높이 3.0, 실물 2.77)은 거의 실물인데, 위·아래 면(`T`, `B`)은 길이 방향으로 눌려 전장 ÷ 날개폭이 0.505(실물 0.627)였다 — 특히 날개 뒤 동체가 실물의 절반쯤. Hunyuan3D는 이 어긋난 그림들로 날개 가로세로비 약 5의 "짧고 뚱뚱한" 모델을 만들었다(컨셉 날개는 약 7.1, 실물 8.8).

## 고친 것

| 파일 | 한 일 |
|---|---|
| `01.Jenny_03_T_fixed.png` | 위면. 기수와 날개는 그대로(별 표식이 둥글게 남도록), 날개 뒤~꼬리날개 앞 동체를 105→204 px, 꼬리를 76→97 px로 늘림(날개폭 713 px = 13.29 m 기준 실물 3.80 m, 1.81 m). |
| `01.Jenny_03_B_fixed.png` | 아랫면. 같은 방식(100 px/m 기준 날개 뒤 동체 290→380 px, 꼬리 130→181 px). 캔버스가 위로 141 px 늘었다. |
| `01.Jenny_03_LS.png`, `_RS`, `_F`, `_R` | 원본 그대로 복사(옆·앞면은 비율이 이미 실물에 가깝다). |

그림체·색·표식·디테일은 건드리지 않았다(가로줄 단위로 늘리기만 함).

## Meshy에서 (사용자)

1. 여러 장 이미지 → 3D(Multi-view)로 `LS`(옆), `F`(앞), `T_fixed`(위), `B_fixed`(아래)를 넣는다. 한 장만 쓰는 방식이면 `LS`.
2. 텍스처 켜기, 좌우 대칭 켜기. 요금제를 기록한다(무료는 CC BY 4.0 — Meshy 표기 필요, 유료는 소유; ZR R10).
3. 결과를 `GDD/characters/aircraft/01.Jenny/jenny_M.glb`(또는 .fbx/.blend)로 저장.

그다음(Claude): 날개폭에 맞춰 크기 조정 → 프로펠러·조종면 분리와 힌지(`export_h_aircraft.py` 방식) → 새 자리·스카프·바퀴·배기 좌표 → 언리얼 임포트 → 확인용 옵션으로 게임 안 비교.
