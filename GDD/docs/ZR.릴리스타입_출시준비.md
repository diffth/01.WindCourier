## 6. 진행 기록

### R1 일시정지·종료 메뉴 (2026-09-28)

- `Esc`(패드 `Start`)로 게임을 멈추고 종이 메뉴를 띄운다: **계속 / 조작 안내 / 게임 종료**. 위·아래(`W`/`S`, 패드 십자키)로 고르고 `Enter`(`Space`, `E`, 패드 `A`)로 정한다. 메뉴에서 `Esc`는 계속(하위 화면에서는 돌아가기).
- 멈추는 동안 세계 시간·소리·세션이 모두 멈춘다(`SetPause`). 메뉴는 HUD가 그리는 동안 입력을 받는다 — 세션은 멈춰 있어 틱이 없다.
- 게임 종료는 한 번 더 묻는다: "하루는 쉴 때 저장된다. 오늘 비행한 것은 남지 않는다."
- 1막 회항 선택이 떠 있는 동안의 `Esc`는 그 선택을 닫는 데 쓰므로 메뉴를 열지 않는다.
- 조작 안내는 1일차 조작 카드와 같은 표를 쓴다(`Esc  일시정지 메뉴` 줄 추가). 화면 아래 도움말 줄에 `Esc: 메뉴`를 붙였다.
- 설정·처음 화면으로는 아직 없다 — R3(설정)·R2(타이틀)에서 메뉴에 붙인다.
- 확인용 `-FlightMenuPreview=main|controls|quit`(2초에 그 화면을 연다, `-FlightShotAt`과 함께). `-FlightShotAt`은 멈춘 동안에도 흐르는 시간으로 바꿨다. 영어·한국어 캡처 확인, 테스트 20개 Success.

### Q3 게임패드 전체 조작 (2026-09-29)

- 배치(사용자 결정, 커서형): 키보드 조작은 그대로 두고 버튼을 더했다.

  | 화면 | 키보드 | 패드 |
  |---|---|---|
  | 카운터 노선 | 1~7 | 십자키 위/아래로 고르고 A로 출발(닫힌 노선은 건너뜀) |
  | 서랍 | 위/아래, L | LB/RB, X |
  | 기체 | H | Y |
  | 언어 | Tab | View |
  | 조작 안내 카드·폭풍 장부 닫기 | E | A |
  | 쉬기 | R | Y |
  | 1막 귀환 선택 | 1 / 2 / Esc | X / Y / B |
  | 비행·편지·저녁·엔딩·크레딧 | E | A (전과 같음) |
  | 메뉴·타이틀·설정 | 방향키·Enter·Esc | 십자키·A·B·Menu (전과 같음) |

- 카운터에서는 E/A가 투하·착륙으로 넘어가지 않는다 — A로 노선을 고르면 비행 첫 몇 초에 "투하 지점이 아니다"가 남던 것을 막았다(저녁·엔딩 닫기는 그대로).
- 표기(사용자 결정): 마지막으로 누른 장치에 맞춰 바뀐다(`FlightInput.h`, 패드 버튼이나 스틱을 크게 움직이면 패드, 키를 누르면 키보드). 패드 이름은 Xbox 기준이다 — 엔진 기본 입력으로는 패드 종류를 알 수 없다. 카운터는 패드일 때 노선 번호 대신 커서(`>`)와 "[십자키] 노선 고르기 [A] 출발"을 보인다. 조작 안내 카드와 메뉴의 조작 페이지도 패드용 목록(같은 줄 수)으로 바뀐다.
- 비행 안내 문구: "E / A", "Shift / RT"처럼 두 장치를 함께 쓰던 말과 키보드만의 말("A나 D를 눌러", "Ctrl로")은 그리는 순간 쓰는 장치의 말만 남긴다(`DeviceWords`). 키보드에서는 "Shift: 출력 Ctrl: 활공 E: 투하"로, 패드에서는 "RT: 출력 LT: 활공 A: 투하"와 "스틱을 좌우로 밀어"로 읽힌다. 패드의 비행 도움말 줄에는 F1·F2가 없다(수채화는 설정에 있다).
- 확인용 옵션 `-FlightGamepadPrompts`(패드 표기로 시작, Shipping에서는 무시).
- 확인: 패드·키보드 표기로 카운터·조작 카드·타이틀·설정·편지·비행 화면 캡처. `NextDay` 테스트에 노선 커서(첫 열린 노선에서 시작, 닫힌 시험비행 건너뜀, 위로 넘기면 마지막 노선) 추가. 테스트 20개 Success, 경로·착륙 검사 PASS(211.343 s, 기준 그대로).
- 남은 것: 실제 패드로 처음부터 엔딩까지 사람 확인. PlayStation 버튼 이름(필요하면 Steam Input 등으로 패드 종류를 알아야 한다).

### 다국어 구조 (2026-10-07)

- 사용자: 배경이 유럽풍이니 유럽 언어도 — 1.0 후보로 독일어·프랑스어·스페인어(추천). 먼저 **구조 변경**만 했다. 영어·한국어 동작은 그대로다.
- 방식: 코드의 `WC_TR("영어", "한국어")` 약 430곳은 그대로 두고, 다른 언어는 **영어 문장을 열쇠로 하는 번역 표** `Content/FlightTest/Data/Translations/<코드>.json`(`{"name": "Deutsch", "strings": {영어: 번역}}`)에서 읽는다. 표에 없거나 빈 문장은 영어로 나온다. 서식 문장(`%d`, `%s`)은 번역이 같은 서식을 같은 순서로 지녀야 하고, 다르면 영어로 나오며 로그에 경고(`LogWindCourierLanguage`). 영어·한국어는 표를 거치지 않고 예전과 같은 길(`FString::Printf` 컴파일 검사도 그대로).
