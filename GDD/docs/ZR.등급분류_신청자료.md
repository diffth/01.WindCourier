### 1.1 게임제작업 등록 (2026-10-12 조사)

"신고"가 아니라 **등록**이다. 근거는 게임산업진흥에 관한 법률 제25조(세부는 시행규칙 제15조).

**결정(2026-10-12): 게임제작업만 등록한다.** 법 제2조에서 배급업은 "제작업자로부터 게임물을 제공받아" 유통하는 영업이다. ozs는 직접 만든 게임을 Steam에 직접 팔므로 제작업에 해당하고, 등급분류 신청에도 "제작업자 또는 배급업자 등록증"이라 제작업 등록증 하나로 된다. 구청에 직접 확인한 것은 아니다 — 구청이 배급업 서류(사업계획서)를 요구하면 만들어 둔 파일을 낸다.

- **제출 파일** (`output/registration/`, git 제외 — 개인정보 포함):
  - 제작시설 및 장비 명세서: `제작시설_및_장비_명세서_ozs.pdf` / `.jpg`(한 장 합본) — 제작업 첨부 서류
  - 사업계획서: `사업계획서_ozs.pdf` / `.jpg` — 배급업 서류라 제작업만 등록하면 내지 않는다(예비)
  - 원본은 Claude Docs: [명세서](https://claude.ai/code/artifact/9d55da26-5b79-4ef4-a401-eb5a7676c1bd) · [사업계획서](https://claude.ai/code/artifact/9fa6a28a-f2f0-4103-a178-6673baf8eb2e)

- **어디서**: 영업소 주소지 관할 시·군·구청 문화(체육) 담당 부서. [정부24](https://www.gov.kr)에서 "게임제작업 등록"으로 온라인 신청하거나 구청에 방문 신청.
- **신청서**: 시행규칙 별지 제4호 서식(게임제작업·게임배급업 등록신청서).
- **구비서류(개인사업자, 제작업)**:
  - 등록신청서
  - 제작시설 및 장비 명세서(개발용 PC 등)
  - 영업소 임대차계약서 사본(임차한 경우만)
  - 신분증(지자체에 따라)
- **처리기간·수수료**: 3일, 20,000원(구청 민원편람 예시 — 수수료는 지자체 조례마다 다를 수 있음).
- **확인할 것**:
  - 등록 전에 영업하면 과태료가 부과될 수 있다는 지자체 안내가 있다. itch.io 무료 데모(2026-10-11 공개)가 '영업'에 해당하는지 구청에 문의.
  - 지자체에 따라 건축물 용도·지방세 완납 여부를 확인한다. 자택을 영업소로 써도 되는지 미리 전화로 확인.
  - GRAC의 [등록 안내 페이지](https://www.grac.or.kr/Institution/Company01.aspx)는 조사 때 방화벽에 막혀 읽지 못했다. 위 내용은 지자체 민원편람 기준.
- **제작품목·취급품목 칸 (추정, 공식 예시 미확인)**:
  - 변경신고 안내에서 제작업은 "제작품목", 배급업은 "취급품목"이라 부른다. 바꾸면 변경신고 대상이므로 너무 좁게 적지 않는다.
  - 게임 이름이 아니라 게임물 종류(플랫폼) 단위로 적는다. 예: "PC 게임" 또는 "PC 게임(다운로드), 모바일 게임". 게임별 심사는 등급분류이고 이 등록은 업종 단위다.
  - 나중에 모바일·콘솔로 낼 생각이면 처음부터 같이 적어 변경신고를 줄인다.
  - 정확한 칸 이름과 기재 예시는 정부24 신청 화면의 "신청작성예시" 또는 구청 전화로 확인.
  - 제작업만 등록하므로 이 칸 이름은 "제작품목"일 것이다.

### 1.2 GCRB 회원가입과 인증서 (2026-10-12 조사)

등급분류 신청은 GCRB **업체회원** 가입·승인 뒤에만 할 수 있고, 가입에 인증서가 꼭 필요하다. 개인사업자도 업체회원으로 가입한다.

- **인증서**: GCRB 전용 인증서를 **무료**로 받는다(홈페이지 메인 "공인인증서 발급"). 게임물관리위원회에서 받은 인증서도 쓸 수 있다. 은행 공동인증서(사업자용)를 쓸 수 있는지는 안내에 없다 — 전용 인증서가 무료라 그걸 받는다.
- **아이핀**: 대표자 실명 확인은 아이핀으로만 된다(휴대폰 인증 불가). 없으면 미리 발급.
- **입력 정보**: 상호명·사업자등록번호·대표자명을 사업자등록 내용과 똑같이 입력.
- 순서: 인증서 발급 → 업체회원 선택 → 약관 동의 → 기업 인증(상호·사업자번호) + 아이핀 실명 확인 → 가입 정보 입력 → 승인 → 로그인(인증서 암호).
- **개인회원**도 있다(휴대폰 인증만, 인증서 없음). 2023-10 보도에서는 개인 개발자가 개인회원으로 신청하면 50% 감면이 자동 적용된다. 다만 사업자등록·제작업 등록을 한 개인사업자가 어느 쪽으로 가입해야 하는지는 안내에 없다 — 가입 전에 GCRB에 전화로 확인한다. 업체회원이면 감면을 따로 신청한다(1.3).

### 1.3 신청 화면·수수료·심사 기간 (2026-10-12 조사)

**심의형으로 신청한다.** 정부24 안내에서 간소화는 "오픈마켓 모바일 게임물"용 설문 방식이다. PC(Steam) 게임은 심의형이다.

**신청 화면 순서** (GCRB 이용안내 "신규신청")
1. 신청서: 담당자 정보, 원작 정보(없음), 배급 정보 — 게임명·배급자·개발연도·플랫폼·장르·**희망등급**.
2. 내용정보기술서: 게임물 개요, 정식명칭·원제명, 이전 등급·해외 등급, 장르, 플랫폼·접속방식, 이용가능 계정, 과금정책, 유통방식, 개발상황, 그리고 선정성·폭력성·약물·범죄·언어·사행성 + **동영상 시간정보**. 2.4절 표와 3.1절 시간 표를 옮긴다.
3. 공통문서: 게임제작업 등록증 (초상권·라이선스 서류는 해당 없음 — 음원은 Freesound 등 크레딧 표기분, 필요하면 목록 첨부).
4. 사용설명서(공개용·비공개용 각각) + 동영상·게임 파일 — 파일 업로드 또는 우편 중 택1.
5. 수수료: 플랫폼·이용형태·장르·한글화를 고르고 입금자명 입력, 입금증 업로드.
6. 신청 완료 → "접수대기" → 심의 끝나면 "등급결정".

**수수료** = 플랫폼 기초가액 × 이용형태 × 장르 × 한글화 ([모의 수수료 계산](https://www.gcrb.or.kr/Mobile_NEW/sub/fee%20calculation.aspx))
- PC 360,000원 × NON 네트워크 1.0 × 한글 1.0 × 장르 계수.
- 장르 계수: 2군(2.0) 어드벤처·캐주얼액션·시뮬레이션 / 3군(1.0) 비행슈팅·스포츠·보드 등. 2.1절대로 "비행 어드벤처"면 **어드벤처 2군 → 720,000원**. 쏘는 요소가 없어 비행슈팅(3군)은 맞지 않는다.
- 부가세: 등급 결정 뒤 세금계산서가 나온다. 모의 계산에 부가세 칸이 있어 10%를 더하면 792,000원(입금 전 모의 계산으로 확정).
- **감면 50%**: 상시 고용 50인 미만·매출 50억 이하 중소기업과 개인 개발자(2023-10-05부터). 업체회원은 "중소기업 감면대상 신청"으로 상시 고용인수 확인서류·매출액 확인서류를 내고 확인받으면 1년간 신청 단계에서 자동 감면된다. 감면되면 약 396,000원.

**동영상**: FAQ 기준 "약 10분" 분량의 주요 진행 과정을 온라인 첨부. 형식·해상도·용량 기준은 없다. 너무 크면 우편·택배·방문 제출. 지금 녹화본(3.1)은 3분 31초라 짧다.

**심사 기간**: 접수일부터 15일 이내(지연되면 사유 통보). 내용 수정 신고는 7일.

### 2.2 게임 개요

전쟁이 끝난 1920년대 유럽풍의 가상 지역에서, 열여섯 살 우편 비행사 리브가 작은 복엽기로 마을과 마을 사이에 편지를 나른다. 플레이어는 바람(스카프·구름·새·상승기류)을 읽으며 비행하고, 마을 위로 낮게 내려가 우편을 떨어뜨리거나 활주로에 내려 편지를 직접 전한다. 하루는 아침 우체국 카운터에서 노선을 고르는 것으로 시작해 저녁에 돌아와 쉬는 것으로 끝나며, 이야기는 3막과 엔딩으로 이어진다.

### 2.3 진행 구조

1. 타이틀 → 처음 시작하면 배경 소개 카드(세 문장)와 조작 안내.
2. 아침 카운터: 오늘의 노선(최대 7개)과 서랍 속 편지를 고른다.
3. 비행: 이륙 → 목적지까지 비행 → 투하 또는 착륙 전달 → 우체국으로 돌아옴.
4. 저녁: 우체국 사람과 짧은 대화, 하루 정산, 쉬기(저장) → 다음 날.
5. 폭풍이 지나가는 날, 산맥을 넘는 장거리 노선, 마지막 편지와 엔딩. 엔딩 뒤에도 열린 노선을 자유롭게 날 수 있다.

| 요소 | 있음/없음 | 설명 |

| 폭력성 | 없음 | 적·싸움·무기가 없다. 기체가 땅이나 능선에 크게 부딪히면 화면이 잠깐 어두워진 뒤 가까운 안전 지점 상공에서 다시 비행한다. 사람이 다치거나 기체가 부서지는 모습, 피는 나오지 않는다. 가볍게 스치면 흔들림과 소리만 난다. 새와 부딪히는 판정은 없다. |

| 주제 | 약함 | 배경이 "전쟁이 끝난 뒤"이고, 주인공의 아버지가 2년 전 비행에서 돌아오지 않았다는 사실이 이야기의 출발점이다. 전쟁·전투 장면은 없고, 아버지의 사고 장면도 나오지 않는다. 이야기는 마을 사람들과 편지를 통해 밝게 마무리된다. |

## 3. 주요 진행 동영상 구성안

"신청서에 쓴 항목은 영상에도 나와야 하고, 실행 과정보다 등급에 영향을 주는 요인을 보여야 한다"는 안내에 맞춰, 등급 요소가 나오는 장면을 빠짐없이 담는다. 영상과 함께 **시간 정보 표**(각 요인이 나오는 시각과 내용)를 낸다. 실제 플레이를 Shipping 1.0 후보 빌드로 녹화한다(OBS 등). 길이 약 10~15분.
