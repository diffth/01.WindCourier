## 1. 하루의 흐름

**업무 확인 → 노선 선택 → 비행 준비 → 이륙 → 비행·배달 → 선택적 탐색 → 귀환·정산 → 정비·편지·대화 → 다음 날**

하루 분량은 준비·귀환·정산을 한 번씩 계산하고, 각 배달의 이동·접근·투하·고도 회복 시간을 합산해 산정한다. 서사 배달에는 착륙·대화·재이륙 시간을 반영한다. 배달 횟수와 하루 길이는 실측 후 정한다(2026-09-18 사용자 결정, D10). 상세 측정 범위는 [비행·코어 루프](03.비행_코어루프.md) 3.1절을 따른다.

첫 하루 흐름 테스트는 정규 배달 2~3회를 기준으로 구성한다. 가까운 일반 배달과 서사 착륙 배달을 섞어 비행·귀환·정비·대화 시간을 기록하고, 테스트 결과로 최종 배달 횟수와 하루 길이를 정한다.

**하루 구성 확정(2026-09-20 사용자 결정, 하루 흐름 4회 측정): 하루는 정규 배달 3회 — 저공 투하 2회와 착륙 전달 1회 — 를 마치고 우체국에 착륙해 정산한다.** 프로토타입 실측에서 비행·배달만의 하루는 6:17~6:48(평균 약 6:28)이었고 매 회차 분량이 적당하다는 평가를 받았다. 준비 장면·대화·편지 읽기·정비·탐색은 아직 포함되지 않은 값이므로 최종 하루는 이보다 길어지며, 하루 수와 콘텐츠 개수는 그 시간을 측정한 뒤 산정한다([측정 기록](P.프로토타입_측정기록.md)).

하루는 업무 주기다. 플레이어는 무엇을 배달할지, 어떤 노선으로 날지, 비행 후 무엇을 할지 선택한다.

**시간대 연출 확정(2026-09-18 사용자 결정, D08): 준비는 아침, 배달은 낮, 귀환·정산은 저녁으로 연출한다.** 비행 중 시간제한으로 귀환을 재촉하지 않으며, 주요 서사 장면에는 지정된 시간대를 사용한다. 기본 시간대는 업무 흐름에 맞춰 전환하고, 전환 시점·연출 길이는 후속 검증에서 정한다. 플레이 시간 실측은 분량 산정용이며 귀환 마감시간으로 사용하지 않는다.

아침에는 날씨·바람·시야, 이용 가능한 노선, 정규 우편과 미배달 우편, 기체 상태를 확인한다. 출발 전에는 연료·적재량과 목적지·예상 거리·위험을 살핀다. 노선은 최단거리보다 바람을 활용할 수 있는 경로가 유리할 수 있다.

정규 우편의 출발 전 안내는 목적지 방향·예상 거리·적재량·위험 요약으로 제한한다. 정확한 투하 구역이나 착륙 지점은 목적지에 접근했을 때 지형 표지와 간단한 접근 표시로 드러낸다. 출발부터 정확한 지점을 표시해 경로 탐색을 대신하지 않도록 하며, 장거리 노선만 예상 왕복 연료와 보급 가능 여부를 함께 보여준다.

2026-09-18 사용자 결정(D03): 장거리 노선은 출발 전에 장거리 표시·예상 왕복 연료 소모량·중간 보급 가능 여부를 안내한다. 출발 전 연료 안내는 게이지와 예상 왕복 소모 비율을 함께 표시하고, 보급 경유가 필요한 노선에는 “중간 보급 필요”와 해당 보급 지점을 명시한다(2026-09-19 사용자 결정). 가까운 배달의 연료 부담은 낮게 유지한다. 구체적인 거리 기준과 소비량은 후속 실측으로 정하며, 안내의 상세 조건은 [비행·코어 루프](03.비행_코어루프.md)에서 관리한다.

중간 보급은 일부 마을의 지정 착륙 지점에서 간단한 상호작용으로 수행한다. 출발 전 지도에 보급 지점을 표시해 경유를 계획할 수 있게 한다(2026-09-18 사용자 결정, D03). 보급 시 연료를 무료로 가득 채우며, 보급 지점은 주요 장거리 노선 가까이에 두어 작은 우회로 들를 수 있게 한다(2026-09-19 사용자 결정). 상세 보급 규칙은 [비행·코어 루프](03.비행_코어루프.md)를 따르며, 정확한 위치와 우회 거리는 후속 노선 설계·실측으로 정한다.

2026-09-19 사용자 결정(D03): 예상 연료가 부족해도 경고 후 출발을 허용한다. 필요한 보급 경유를 안내하고 최종 출발 판단은 플레이어에게 맡긴다. 상세 부족 안내 규칙은 [비행·코어 루프](03.비행_코어루프.md)를 따른다.

2026-09-18 사용자 결정(D08): 기본은 당일 귀환이다. 강풍 때문에 편도로 운항하고 다음 날까지 기다려야 하는 이전 안은 채택하지 않는다.

## 2. 업무 선택

| 종류 | 역할 | 특징 |
|---|---|---|
| 정규 우편 | 일상 업무와 반복 플레이 | 목적지가 명확하고 반복 가능하며, 배달 기록·꾸미기 해금과 비행 숙련 기회를 제공 |
| 미배달 우편 | 자발적 탐색과 서사 | 수취인·목적지를 추적하고 새로운 NPC·장소·메인 이야기와 연결 |

정규 노선만 수행해도 일상 업무를 진행할 수 있어야 한다. 미배달 우편은 원할 때 선택한다. 메인 서사 미배달 편지는 총 6통으로, 1막 1통·2막 3통·3막 2통을 배치한다. 1막의 에다 로웬 편지는 벨로아 주변 첫 탐색 뒤 해금한다. 2막의 니코 페른 편지는 아르덴느 진입과 함께, 마르타 벨 편지는 첫 산악 배달 완료 뒤, 루카스 하른 편지는 호수 지대 노선 해금 뒤 선택할 수 있게 한다. 3막의 셀마 오르 편지는 노르드발 진입 전에 선택할 수 있다. 마지막 리브 편지는 3막 진입 때 오스카가 아버지의 배달 장부를 통해 위치를 안내하면 해금한다. 셀마 방문·사진·메모 확인은 해금 조건이 아니다. 수취인과 초안은 [미배달 편지 초안](P.편지_초안.md)을 기준으로 하며, 1~5번은 선택이고 마지막 6번만 엔딩 조건에 포함한다(2026-09-18 사용자 결정). 엔딩 이후 플레이는 아래 11절을 따른다.

미완료 선택 편지 1~5번은 막 전환이나 엔딩으로 만료되지 않는다(2026-09-18 사용자 결정). 이미 해금한 편지는 계속 선택·전달할 수 있고, 아직 해금하지 않은 편지의 탐색·노선 조건도 이후에 충족할 수 있게 한다. 완료 여부와 발견한 단서를 보존하며, 선택 편지를 늦게 전달해도 이전 막이나 엔딩을 다시 실행하지 않는다.

## 3. 비행과 노선

비행의 중심은 바람과 고도 관리다. 방향·속도·연료·시야를 한꺼번에 과도하게 관리하게 만들지 않는다. 세부 조작·날씨·연료 수치는 [비행·코어 루프](03.비행_코어루프.md)에서만 관리한다.

| 지역 예시 | 비행 경험 |
|---|---|
| 평야 | 안정적인 비행 |
| 강가 | 상승기류 탐색 |
| 산맥 | 난기류와 고도 판단 |
| 호수 | 강풍 대응 |
| 북부 | 안개 속 시야 판단 |

지역 배치 확정(2026-09-18 사용자 결정): 세 지역을 하나의 생활권으로 연결하고 벨로아를 중심으로 재방문한다.

| 지역 | 역할 | 주요 노선 |
|---|---|---|
| 벨로아(Belloa) | 우체국과 출발 마을. 강과 평야의 입문 구간 | 벨로아 ↔ 아르덴느, 벨로아 ↔ 강가 우편함 |
| 아르덴느(Ardenne) | 능선과 계곡. 상승기류와 산악 노선 | 벨로아 ↔ 아르덴느, 아르덴느 ↔ 호수 지대 |
| 노르드발(Nordval) | 북부 안개·산악 지대. 마지막 서사 노선 | 아르덴느 ↔ 노르드발, 노르드발 ↔ 등대 |

1막은 벨로아 주변 평야·강가, 2막은 아르덴느와 호수 지대, 3막은 노르드발과 등대를 연다. 세 지역은 막이 진행되어도 기존 노선을 재방문할 수 있으며, 마을 변화는 막 진행과 편지 전달 반응 원칙을 따른다. 구체적인 노선 거리와 배달 지점은 비행 실측 후 조정한다.

### 서사 편지의 세부 장소

2026-09-18 사용자 결정: 기존 편지 초안의 지명은 세 지역 안의 세부 장소명으로 유지한다. 별도의 추가 지역으로 계산하지 않는다.

| 지역 | 세부 장소 | 편지·방문 시점 |
|---|---|---|
| 벨로아 | 루메 해안 | 에다 로웬 · 1막 |
| 아르덴느 | 오르델 계곡 | 니코 페른 · 2막 |
| 아르덴느 | 세르노 강가 | 마르타 벨 · 2막 |
| 아르덴느 | 브레나 산간 학교·정비소 | 루카스 하른 · 2막, 셀마 오르 · 3막 재방문 |
| 노르드발 | 노르바 등대 | 리브의 마지막 편지 · 3막 |

브레나의 학교와 정비소는 같은 장소의 별도 시설로 구성한다. 셀마를 만나러 가는 길은 3막의 아르덴느 재방문이며, 노르드발 진입이나 엔딩의 필수 경유지가 아니다. 세부 장소 사이의 거리와 착륙 지점 좌표는 비행 실측 후 정한다.

## 4. 배달과 보상

배달은 누구에게 무엇을 전달했는지가 중요하다. 복잡한 미니게임으로 만들지 않는다.

**일반 우편은 저공 투하, 중요한 서사 편지는 착륙 전달을 병행한다(2026-09-18 확정, D02).** 일반 배달은 비행의 흐름을 이어가고, 서사 배달은 사람을 만나 편지의 의미를 느끼는 시간을 제공한다.

**투하 판정 확정(2026-09-18 사용자 결정, D02): 넓은 배달 구역에 적정 고도로 진입하면 투하 가능 표시를 제공하고, 버튼 하나를 누르면 배달에 성공한다.** 정밀 조준과 타이밍 점수는 제외한다. 투하하지 않고 구역을 지나치면 우편을 유지한 채 재접근한다. 조건을 만족하지 않은 상태의 입력으로 우편을 잃지 않는다. 첫 프로토타입에 이 방식을 적용해 비행 흐름과 재접근의 부담을 확인한다. 구역 크기·허용 고도·버튼 배치는 후속 검증에서 정한다. 착륙 전달은 후속 검증에 포함한다.

엔진은 간단한 조작을 지향하고 연료는 장거리에서만 실질적인 제약으로 사용한다. 일상적인 가까운 배달에서는 재접근과 고도 회복에도 연료 여유를 준다. 투하 후에는 엔진 출력 보조만으로 기류에 다시 진입할 고도를 확보할 수 있고, 상승기류를 이용하면 더 수월하게 상승한다(D10, 2026-09-18 사용자 결정). 상세 입력안과 수치는 [비행·코어 루프](03.비행_코어루프.md)에서 관리한다.

**배달 보상 확정(2026-09-19 사용자 결정): 첫 완성판은 돈·평판 수치 없이 배달 기록과 꾸미기 해금으로 보상한다.** 배달을 마치면 완료 기록을 남긴다. **배달에 따른 꾸미기 해금은 서로 다른 노선의 첫 배달 완료를 기준으로 한다(2026-09-19 사용자 결정).** 같은 노선을 반복한 누적 배달 횟수는 해금 기준으로 사용하지 않으며, 막 진행에 따른 해금도 유지한다. 첫 완료 기록은 날짜·막 전환·엔딩 이후에도 유지해 같은 노선의 첫 완료 보상을 다시 지급하지 않는다. 노선별·막별 보상 목록과 개수는 후속 설계에서 정한다. 이야기 진행에 따른 노선·장소 해금, 인물의 반응과 관계 변화, 미배달 우편 단서는 각 서사 규칙을 따른다. 우편 수익·평판을 수치로 누적하거나 기체 관련 자원을 보상으로 지급하지 않으며, 상점·제작 재료도 추가하지 않는다.

**첫 배달 보상의 노선 구분 확정(2026-09-19 사용자 결정): A→B와 B→A는 하나의 노선으로 취급한다.** 어느 방향이든 먼저 배달을 완료하면 해당 노선의 첫 보상을 지급하고, 반대 방향의 배달에는 첫 보상을 다시 지급하지 않는다. 양방향을 모두 완료해야 보상을 받는 조건은 아니며, 각 배달의 완료 기록은 남긴다.

**노선별 꾸미기 보상 확정(2026-09-19 사용자 결정): 각 노선의 첫 배달에는 미리 정해진 꾸미기를 지급한다.** 플레이어가 공통 꾸미기 목록에서 선택하지 않으며, 노선의 풍경·분위기와 연결된 도장 색상·스카프 색상·기체 표식을 보상으로 배치한다. 막 진행 보상도 미리 정한 꾸미기를 지급한다. 정확한 노선별 꾸미기 매핑과 목록은 후속 설계에서 정한다.

노선별 꾸미기 범주는 노선의 풍경과 분위기에 맞춰 고정 배치한다(2026-09-19 사용자 결정). 해안·호수처럼 색감과 지형 인상이 강한 노선은 도장, 바람과 고도 변화가 두드러지는 산악 노선은 스카프처럼 지역 경험을 외형에 연결한다. 실제 노선별 색상·문양·범주 매핑은 후속 아트 설계에서 정한다.

**꾸미기 해금 시점 확정(2026-09-19 사용자 결정): 노선의 첫 배달을 완료한 즉시 꾸미기를 해금한다.** 우체국 귀환이나 하루 정산을 기다리지 않으며, 배달 완료 연출 직후 해금 알림과 적용 가능한 꾸미기를 표시한다. 막 진행으로 해금되는 꾸미기도 해당 진행 장면이 완료되는 즉시 해금한다. 해금 알림의 문구와 표시 시간은 후속 UI 검증에서 조정한다.

노선 첫 배달로 꾸미기를 해금할 때는 지역·노선 이름과 꾸미기 이름을 함께 5초 동안 표시한다(2026-09-19 사용자 결정). 예시는 “아르덴느 산악 노선 완료 — 회색 능선 스카프 해금”과 같다. 막 진행 표식은 막 이름과 표식 이름을 함께 5초 동안 표시한다. **두 해금 알림 중에도 비행 조작을 계속 허용하며, 자동 정지나 입력 잠금을 사용하지 않는다.** 저고도·충돌·투하 같은 비행 경고가 동시에 발생하면 경고를 우선하고 해금 알림은 잠시 숨긴다. 경고가 끝난 뒤 5초 타이머의 남은 시간만 다시 표시한다(2026-09-19 사용자 결정). 알림의 세부 문구와 배치는 후속 UI 검증에서 조정한다.

**꾸미기 적용 방식 확정(2026-09-19 사용자 결정): 해금된 꾸미기는 즉시 현재 기체에 자동 적용한다.** 플레이어가 별도 메뉴를 열거나 격납고로 돌아갈 필요 없이 배달 완료·막 진행 장면 직후 외형이 바뀐다. 이후 격납고에서 해금한 꾸미기를 다시 선택해 바꿀 수 있으며, 자동 적용은 성능 수치에 영향을 주지 않는다. 적용 전환 연출과 알림 문구는 후속 UI 검증에서 조정한다.

**꾸미기 적용 범위 확정(2026-09-19 사용자 결정): 해금 보상은 당시 사용 중인 기체에만 적용한다.** 다른 기체의 도장·스카프·표식은 바뀌지 않으며, 각 기체는 해금한 꾸미기 중 원하는 외형을 격납고에서 따로 선택할 수 있다. 보상 해금 기록 자체는 계정·세이브에 공통으로 유지한다. 적용 범위와 해금 기록의 표시 방식은 후속 UI 검증에서 조정한다.

**꾸미기 범주 적용 확정(2026-09-19 사용자 결정): 같은 범주의 새 꾸미기를 해금하면 현재 기체의 해당 범주를 새 항목으로 교체한다.** 도장·스카프·기체 표식은 각각 하나씩 적용하며, 여러 도장이나 표식을 겹쳐 적용하지 않는다. 이전에 해금한 항목은 세이브에 남아 격납고에서 다시 선택할 수 있다. 교체 알림과 격납고 선택 UI는 후속 검증에서 다듬는다.

**노선별 꾸미기 지급 수량 확정(2026-09-19 사용자 결정): 서로 다른 노선의 첫 배달을 완료할 때마다 꾸미기 1개를 지급한다.** 도장·스카프·기체 표식 중 어느 범주를 지급할지는 노선의 풍경·분위기와 전체 수집 구성을 기준으로 미리 정한다. 한 노선에서 여러 꾸미기를 한꺼번에 지급하지 않는다.

**막 진행 꾸미기 범주 확정(2026-09-19 사용자 결정): 막 진행 보상은 기체 표식 1개로 지급한다.** 1막·2막·3막의 진행을 기체에 남기는 상징적인 표식으로 사용하며, 노선 첫 배달 보상과 별도로 해금한다. 표식의 모양과 문양은 각 막의 지역·이야기 분위기에 맞춰 후속 아트 설계에서 정한다.

**꾸미기 보상 매핑 확정(2026-09-19 사용자 결정):** 노선 첫 배달 보상은 아래처럼 노선당 1개로 고정한다. A→B와 B→A는 같은 노선으로 취급하며, 어느 방향이든 첫 완료 시 한 번만 지급한다.

| 노선 | 첫 배달 보상 | 범주 | 분위기 연결 |
|---|---|---|---|
| 벨로아 ↔ 강가 우편함 | 강물빛 도장 | 도장 | 강과 평야의 맑은 색 |
| 벨로아 ↔ 아르덴느 | 능선 회색 스카프 | 스카프 | 산맥 진입과 맞바람 |
| 아르덴느 ↔ 호수 지대 | 호수 청색 도장 | 도장 | 호수와 흐린 수면 |
| 아르덴느 ↔ 노르드발 | 안개 흰색 스카프 | 스카프 | 북부 안개와 시야 |
| 노르드발 ↔ 노르바 등대 | 등대 주황 표식 | 표식 | 마지막 등대와 귀환 |

막 진행 보상은 1막 `첫 우편 표식`, 2막 `능선 통과 표식`, 3막 `노르바 등대 표식`으로 각각 1개씩 지급한다. 해금 즉시 현재 기체에 적용하고, 이전 항목은 격납고에서 다시 선택할 수 있다.

**프로토타입 구현(2026-09-24, 사용자 결정)**: 노선 매핑 — 가까운 배달 = 벨로아↔강가(강물빛 도장), 장거리 = 벨로아↔아르덴느(능선 회색 스카프), 호수 노선 = 아르덴느↔호수(호수 청색 도장), **처음 노르드발 안개(북쪽 10 km)에 들어갈 때** = 아르덴느↔노르드발(안개 흰색 스카프, 정규 노선이 없어 대신함), 마지막 편지 = 노르드발↔등대(등대 주황 표식). 막 표식은 1막(2막 진입 때)·2막(3막 진입 때)·3막(엔딩 때) 끝에 준다. **마지막 편지를 전하는 순간 등대 주황 표식과 3막 표식이 겹치므로 알림을 차례로 보여주고 3막 표식을 최종 적용한다.** 도장은 기체 색, 스카프는 스카프 선 색, 표식은 꼬리날개의 작은 판으로 표현한다. 격납고에서 다시 고르는 화면은 아직 없다(자동 적용만).

**착륙 보조 확정(2026-09-18 사용자 결정, 2026-09-19 보조 범위·시작 방식 결정): 플레이어가 착륙 지점까지 직접 접근하고, 넓은 속도·고도·방향 범위 안에서 E 버튼을 누르면 마지막 접지와 정지를 보조한다.** 조건 충족만으로 자동 시작하지 않으며, 시작 후 약간의 접근 오차를 흡수해 착륙 전달의 흐름을 유지한다. 조건 밖 입력은 보조를 시작하지 않고 재접근할 수 있게 한다. 착륙 보조 조건을 놓친 것만으로 실패·복귀 처리하지 않으며, 실제 충돌로 비행을 계속할 수 없는 경우에는 D04 복귀 규칙을 적용한다. 보조 시작 후에는 중간 취소 없이 접지·정지까지 진행하고, 기체가 정지하면 보조를 종료한다(2026-09-19 사용자 결정). 허용 범위·보조 강도는 후속 착륙 검증에서 조정하며, 상세 규칙은 [비행·코어 루프](03.비행_코어루프.md)를 따른다.

착륙 접근 중 조건이 부족하면 속도·고도·방향에 맞춰 필요한 조작을 짧게 안내하고, 조건을 충족하면 E 버튼 착륙 안내를 표시한다(2026-09-19 사용자 결정, D04·D07). 상세 안내 규칙은 [비행·코어 루프](03.비행_코어루프.md)를 따른다.

착륙 보조 중에는 기존 비행 카메라를 유지해 접근부터 접지·정지까지 시점을 이어간다(2026-09-19 사용자 결정, D04). 상세 카메라 규칙은 [비행·코어 루프](03.비행_코어루프.md)를 따른다.

착륙 전달 후에는 전달·대화를 마치고 수취인 장소에서 가까운 안전한 평지에 마련한 이륙 위치에서 출발한다(2026-09-19 사용자 결정). 1.5초 카메라 전환 중 기체를 다음 목적지 방향으로 부드럽게 정렬하고, 약 2초의 짧은 활주 뒤 자동 이륙한다. 플레이어가 지상에서 방향을 맞출 필요는 없다. 지상 활주 조작은 간소화하고 출력 보조로 재이륙하며, 가까운 배달은 재이륙에도 연료 여유를 준다(2026-09-18 사용자 결정, D10). 소요 시간과 연료량은 후속 착륙 전달 테스트로 조정한다.

자동 활주 중 장애물이나 위험 지형이 감지되면 자동 이륙을 중단하고 안전 지점에 정지한다(2026-09-19 사용자 결정). 같은 이륙 지점에서 위험이 사라질 때까지 시간 제한 없이 대기하며, 대기 중에는 플레이어 입력을 무시한다. 중단 안내는 3초 동안 표시한 뒤 숨기고, 위험이 해소되면 같은 절차로 자동 활주·이륙을 다시 시작한다. 충돌을 감수하고 이륙을 강행하지 않는다.

**착륙 전달의 표현 방식 확정(2026-09-19 사용자 결정):** 착륙 후 리브가 직접 걷는 구간은 두지 않고, 수취인과의 짧은 전달 연출로 바로 연결한다. 플레이어가 전달·대화 버튼을 한 번 누르면 준비된 전체 장면이 자동으로 재생된다. 수취인의 표정·동작과 편지 반응을 보여준 뒤, 전달 완료를 표시하고 준비된 이륙 위치로 카메라를 전환해 기존의 간소화된 재이륙을 시작한다. 장면 중간에 대사를 넘기거나 선택하는 입력은 두지 않는다. 별도 도보 조작·작은 지상 탐색은 첫 완성판의 착륙 전달 범위에 넣지 않는다.

재이륙 때는 카메라를 지정된 이륙 지점으로 **1.5초 동안 전환**하고, 전환이 끝나면 짧은 활주 보조를 거쳐 자동으로 지면을 벗어난다. 플레이어가 지상에서 방향을 맞추거나 출력 보조를 계속 누를 필요는 없다. 지면을 벗어난 직후에는 기체 뒤쪽을 **1초 동안 보여준 뒤** 기존 비행 카메라로 복귀한다. 이 후방 구간이 끝나면 일반 비행 조작으로 복귀해 플레이어가 다음 경로와 기류를 판단한다. 1.5초 전환·짧은 활주·자동 이륙·1초 후방 구간 중에는 방향 입력을 받지 않는다. 재이륙에는 가까운 배달의 **기본 연료량**을 사용하며 별도 10%·20% 보너스는 붙이지 않는다. 카메라 흐름·자동 이륙·기본 연료량은 2026-09-19 사용자 결정이며, 실제 전달 장면에서 여운·후방 구도의 인상·조작 복귀·자동 연출처럼 느껴지는 정도·재이륙 후 연료 부담을 후속 검증한다.

## 5. 탐색과 귀환

배달 뒤 바로 귀환하거나 주변을 탐색한다. 오래된 우편함, 버려진 격납고, 숨겨진 장소, 새 상승기류, NPC 흔적, 미배달 우편 단서가 탐색 대상이다. 첫 비행 출발 전에는 오스카가 새떼가 도는 곳의 상승기류를 알려주며, 이후에는 월드 단서를 보고 스스로 기류를 찾는다(2026-09-19 사용자 결정).

첫 실제 상승기류에 진입하면 화면 아래 중앙에 한 번만 3초 동안 “상승기류에 들어왔습니다”, 위쪽 화살표, “상승 중” 문구를 함께 표시한다(2026-09-19 사용자 결정, D09). 안내 중에도 일반 비행 조작을 계속 허용해 흐름을 끊지 않으며, 현재 고도·상승·하강 상태 안내와 같은 영역에서 읽도록 한다. 같은 게임 세션의 이후 상승기류 진입에는 반복 안내 없이 새떼·구름·소리와 기체 움직임으로 판단하게 한다. 새 게임 세션을 시작하면 첫 진입 때 안내를 다시 한 번 표시한다.

**재방문 변화 원칙(2026-09-18 사용자 결정): 마을의 큰 변화는 막 진행에 맞추고, 편지 전달 직후에는 관련 인물의 짧은 반응을 보여준다.** 일수마다 새 변화를 제작하는 방식은 사용하지 않는다. 같은 마을을 다시 찾을 때 이야기의 진행을 느끼고, 편지 전달 직후에는 배달의 결과를 알 수 있게 한다. 반응은 D06의 짧은 텍스트·표정·동작 원칙을 따르며, 일반 우편의 저공 투하 흐름을 유지하도록 표현한다. 마을별 변화 내용과 편지별 반응 대상·표시 방식은 후속 서사 설계에서 정한다.

일반 배달에서는 출발과 귀환 사이 풍향·세기가 제한적으로 달라져 같은 노선에서도 경로를 다시 판단하게 한다. 변화는 해당 기체로 비행·당일 귀환이 가능한 범위로 제한하며, 변화 폭과 빈도는 실측으로 정한다. 중요한 이야기 장면의 날씨는 [비행·코어 루프](03.비행_코어루프.md)의 고정 연출 규칙을 따른다.

2026-09-18 사용자 결정(D08), 2026-09-19 안내 방식 결정: 바람이 바뀌기 전에 구름의 움직임·바람 소리·스카프 흔들림으로 예고하고, 풍향과 세기는 서서히 변하도록 한다. 별도 HUD 문구는 띄우지 않고 월드 단서만 사용한다. 플레이어가 변화를 알아차리고 경로를 판단할 여유를 주며, 예고 시간과 전환 속도는 후속 비행 실측으로 정한다.

일반 배달의 초기 변화는 배달당 한 번 이하, 풍향·세기 최대 ±10%로 제한한다. 변화 20초 전부터 예고하고 10초 동안 전환한다. 전환이 끝난 뒤의 바람은 현재 배달이 끝날 때까지 유지하고, 다음 배달은 기본 바람 조건에서 시작한다. 가까운 노선과 당일 귀환 가능성을 해치지 않는 범위에서만 적용하며, 주요 서사 장면의 고정 날씨에는 적용하지 않는다.

첫 완성판에서는 수평으로 이동하는 상승기류를 제외하고, 일반 바람의 방향·세기 변화와 상승기류의 생성·소멸에 집중한다(2026-09-18 사용자 결정). 이동하는 기류를 쫓는 조작은 별도 실험으로 남긴다.

## 6. 실패와 복귀

**2026-09-18 사용자 결정(D04): 실패하면 가까운 안전 지점에서 부담 없이 다시 시도한다.** 짧고 완결된 게임의 흐름을 유지하고, 이미 수행한 배달을 반복하기보다 경로를 바꾸어 다시 도전하게 한다.

충돌이나 연료 고갈로 비행을 계속할 수 없으면 짧은 암전 후 가까운 안전 지점으로 복귀한다(2026-09-19 사용자 결정).

**연료 고갈 후 복귀 연출 확정(2026-09-19 사용자 결정, D04): 큰 충돌과 동일하게 조종을 잠시 중단하고 짧은 암전 후 안전 지점으로 복귀한다.** 화면이 돌아오면 조종을 재개할 수 있게 한다. 암전 길이와 조작 복귀의 체감은 큰 충돌과 함께 후속 플레이 테스트에서 검증한다.

**충돌·손상 처리 확정(2026-09-18 사용자 결정, D04): 가벼운 접촉은 흔들림·소리로 알리고 비행을 이어간다. 비행을 계속하기 어려운 큰 충돌은 짧은 암전 후 안전 지점으로 복귀한다(2026-09-19 복귀 연출 결정).** 첫 완성판에서는 누적 내구도 관리와 부품별 고장을 제외한다. 접촉의 경중을 나누는 판정 기준과 흔들림·소리의 강도, 암전 길이는 후속 검증에서 조정한다.

2026-09-19 사용자 제안인 첫 비행의 새 충돌은 [시놉시스](02.시놉시스.md)의 새와의 관계 에피소드 초안에서 관리한다. 현재 안은 비행을 계속하는 가벼운 일회성 접촉 연출이며, 일반 새떼를 반복 충돌 위험으로 만드는 시스템은 아니다. 현재 프로토타입의 새떼에는 충돌 판정이 없다. 이후 함께 비행하거나 날개에 앉는 장면을 포함한 구체적인 연출과 구현 범위는 미결이다.

- 완료한 배달과 발견한 단서는 유지한다.
- 미배달 편지는 그대로 보유하고 다시 시도한다.
- 수리비를 부과하거나 하루 전체를 다시 시작하게 하지 않는다.
- 안전 지점은 우체국과 지정 착륙 지점을 활용한다(2026-09-18 사용자 결정, D04).
- 복귀 후에는 안전 지점 근처에서 비행 중인 기체와 가까운 보급 지점까지 비행할 수 있는 연료를 제공한다(2026-09-18 연료 원칙, 2026-09-19 복귀 상태 결정, D04). 구체적인 연료량은 복귀 위치에서 보급 지점까지의 이동·접근·착륙 조건을 포함해 노선 검증 때 정한다.

**복귀 직후 기체 상태 확정(2026-09-19 사용자 결정, D04): 큰 충돌·연료 고갈 모두 안전 지점 근처 공중에서 비행 중인 상태로 재개한다.** 암전이 끝나 화면이 돌아오면 즉시 일반 비행 조작으로 경로를 다시 잡을 수 있게 한다. 안전 지점 주변의 복귀 위치·고도·속도·방향은 장애물과의 여유 및 조종 재개에 필요한 시간을 고려해 후속 노선 테스트에서 정한다.

**복귀 직후 보급 안내 확정(2026-09-19 사용자 결정, D04·D07): 화면이 돌아오면 복귀 위치에서 실제 비행 경로 거리가 가장 짧은 보급 지점을 잠시 안내한다.** 큰 충돌·연료 고갈 복귀 모두에 적용하며, 제공된 연료로 이동할 수 있는 보급 지점을 알려 경로를 다시 잡도록 돕는다. 원래 목적지와의 거리나 배달 경로보다 복귀 위치에서 보급 지점까지의 비행 가능 경로 거리를 우선한다. 보급 안내는 일시적으로 표시하고 이후 기존 목적지 안내로 돌아간다. 표시 시간·배치·최종 문안은 후속 복귀·UI 검증에서 조정한다.

경로 거리가 같은 보급 지점이 여러 곳이면 장애물 여유·착륙 접근 폭·지정 안전 상태를 비교해 더 안전한 착륙 지점을 우선한다(2026-09-19 사용자 결정). 안전성 평가 기준과 동률 처리의 세부 수치는 후속 노선 검증에서 정한다.

복귀 시 제공된 연료로 선택된 보급 지점까지 도달하기 어려워도 해당 지점을 안내하고 출발을 허용한다(2026-09-19 사용자 결정). 안내에는 “보급 지점까지 연료 부족 예상” 경고를 함께 표시하며, 플레이어가 다른 경로·착륙 지점을 직접 판단할 수 있게 한다. 출발을 제한하거나 보급 지점을 자동으로 바꾸지 않는다. 보급 지점 안내는 화면 복귀 후 5초 동안 표시하고, 이 시간에는 플레이어가 방향을 바꿔도 처음 선택한 지점을 유지한다(2026-09-19 사용자 결정). 이후 기존 목적지 안내로 돌아간다.

안전 지점의 구체적 배치와 복귀 지점 선택 기준은 후속 노선 설계에서 정한다. 지정 착륙 지점 중 보급 가능한 곳은 출발 전 지도에 표시하는 보급 규칙을 따르며, 안전 지점이라는 이유만으로 모든 지점에 보급 기능을 부여하지 않는다.

복귀 지점은 현재 위치에서 가장 가까우면서 식별 가능한 우체국 또는 지정 착륙 지점을 우선한다. 복귀 후에는 즉시 조종 가능한 기체 상태와 가까운 보급 지점까지 이동할 예상 연료에 20% 여유를 더해 제공한다. 가벼운 접촉은 흔들림·소리만 재생하고, 큰 충돌은 조종을 잠시 중단하고 짧게 암전한 뒤 안전 지점으로 복귀한다(2026-09-19 사용자 결정). 화면이 돌아오면 조종을 재개할 수 있게 한다. 암전 길이와 조작 복귀의 체감은 후속 플레이 테스트에서 검증한다.

이전의 수리 비용·시간 페널티와 당일 배달 전체 실패 후 다음 날 시작하는 안은 채택하지 않는다. 착륙 보조는 위의 직접 접근·조건 충족 후 접지와 정지 보조 원칙을 따른다. 충돌 판정의 임계값과 구체적인 연출은 후속 구현 세부로 남긴다. 장거리에서의 연료 판단은 유지하되, 고갈 후 재도전이 막히지 않게 한다.

**폭풍 휴식(2026-09-24 프로토타입 구현)**: 2막에 들어간 다음 날이 한 번의 폭풍 휴식이다. 비행하지 않고(기체 고정, 연료 소모 없음) 오스카가 아버지의 장부를 펼쳐 "폭풍이 지나가면 북쪽으로 갈 수 있어."라고 말한다. 장부를 덮어야(필수 내용) 휴식이 나타나고, 휴식을 골라야 다음 날로 넘어간다. 장거리 노선은 폭풍 다음 날부터 열린다. 셀마 사진·메모 등 선택 내용, 폭풍 날씨 연출, DH-4, 저녁 화면은 아직 없다.

**격납고(2026-09-24 프로토타입 구현)**: 2막부터 우체국 카운터의 `[H]`로 그날 탈 기체를 바꾼다 — 2막은 Jenny·DH-4, 3막부터 Mailwing까지 세 기체를 차례로 돈다. 선택은 저장되어 다음 날로 이어지고, 해금 전 막에서는 Jenny로 돌아간다. 겉모습은 아직 Jenny의 임시 도형을 늘이거나 줄인 것이다(DH-4는 크게, Mailwing은 날개가 길고 몸통이 낮게).

**서랍의 2막 편지(2026-09-24 프로토타입 구현, 구현명세 22 1단계)**: 서랍이 여러 통을 담는다. 에다에 이어 니코(오르델 계곡)는 폭풍 뒤 장거리가 열린 날부터, 마르타(세르노 강가)는 첫 산악 배달 뒤, 즉 3막 전환 다음 날부터 열린다. 모두 착륙 전달이며 선택이다. 방향키 `↑` `↓`로 편지를 골라 `[L]`로 싣거나 다시 내려놓으며, 여러 통을 함께 싣고 다닐 수 있다(사용자 결정. 처음에는 `[L]`이 서랍 순서대로만 실어 마지막 편지 하나만 실을 수 없었다 — 2026-09-24 5회차 확인 비행 뒤 변경). 편지마다 서랍·실림·전달 상태가 다음 날로 이어진다. 루카스·셀마와 브레나(정비소 보급 포함)는 호수 지대가 생기는 2단계로 미뤘다.

**호수 지대와 브레나(2026-09-24 프로토타입 구현, 구현명세 22 2단계)**: 카운터에 `[4] LAKE RUN`이 더해져 장거리와 같은 날(폭풍 뒤)에 열린다 — 호숫가 마을 (−8, +7) km에 투하하고 돌아온다. 브레나 (−13, −1) km에는 학교와 정비소가 800 m 떨어진 별도 활주로로 있다. 루카스(학교)는 호수 노선이 열리는 날부터, 셀마(정비소)는 3막부터 열린다. **정비소는 보급 지점**이며 S처럼 하루 한 번 탱크를 채운다. 셀마의 편지는 정비소에 내려 급유할 때 함께 전달된다. 호수·고원 지형과 셀마의 사진·메모는 아직 없다.

**2막 종료(2026-09-24 프로토타입 구현)**: 폭풍 뒤 2막에서 장거리 노선을 날아 우체국에 착륙하는 순간 3막이 된다(다음 날이 아니라 귀환 시점, 시놉시스 2막 종료 조건). 그날 정산 카드 위에 오스카의 전환 대사 두 줄과 `LAST LETTER - Norva lighthouse, Nordvall`이 뜬다. 다음 날부터 서랍에 마지막 편지가 주소로만(수취인 없이) 들어온다.

**마지막 편지와 엔딩(2026-09-24 프로토타입 구현, 구현명세 22 3단계)**: 마지막 편지는 다른 서랍 편지처럼 `[L]`로 싣고 노르바 등대(−8, +15 km, 맵 북쪽 끝)에 착륙해 전한다. 서랍에 있는 동안 오스카의 첫 줄은 엔딩 직전 대사 "마지막 편지도 우편이야. 네가 직접 전하면 돼."다. 전달 장면은 편지_초안 6의 편지 전문 세 줄과 "리브는 편지를 접어 주머니에 넣는다."(18초)이며, 그 뒤 여느 착륙 전달처럼 다시 이륙한다. 3초 뒤부터 `[E]`로 편지를 닫고 바로 이륙할 수 있다(2026-09-24 사용자 결정: 6회차에서 닫을 방법이 없어 다른 키를 누르다 Play를 끝냈다). 엔딩은 저장되어 반복하지 않고, 이후 날들은 평소대로 이어진다. **"바람이 대답한다"(사용자 결정 A안)**: 마지막 편지를 실은 날은 그날 기본 바람이 등대 쪽으로 불어 스카프·바람 줄기가 길을 가리키고 뒷바람이 된다 — 방향만 정할 뿐 새 규칙은 없고 목적지 표식도 그대로다. **노르드발 안개(D08)**: 북쪽 10 km부터 12 km까지 높이 안개가 기본의 6배로 짙어진다. 절벽 마을, 노르드발 정규 노선, 막 진행 표식, 스카프 마지막 컷, 엔딩 후 정규 우편 카드 정렬은 아직 없다.

폭풍은 이야기에서 정한 휴식 장면으로 사용한다. 비행 대신 편지 분류·대화·정비·정보 획득·다음 날 준비를 배치해 게임의 템포를 바꾼다. 무작위 폭풍이나 연속 폭풍으로 진행을 막지 않으며, 실제 시간을 기다리게 하지 않는다.

날씨 배치 확정(2026-09-18 사용자 결정): 1막의 첫 비행과 벨로아 주변은 맑은 오후, 2막의 아르덴느 진입과 산악 노선은 흐림·강풍, 2막 전환 직후는 한 번의 폭풍 휴식 장면, 3막의 노르드발 마지막 노선은 안개로 고정한다. 일반 배달의 제한적 풍향·세기 변화는 이 고정 장면 사이에서만 적용한다.

시간대는 실시간 시계가 아니라 업무 상태로 전환한다. 우체국에서 하루를 시작하면 아침, 첫 이륙 후 배달·탐색 중에는 낮, 마지막 귀환 후 우체국 정산을 시작하면 저녁으로 바뀐다. 플레이어가 낮에 오래 비행해도 자동 실패나 강제 귀환은 발생하지 않으며, 저녁 전환은 귀환을 마친 뒤에만 일어난다. 폭풍 휴식에서 다음 날을 선택하면 다시 아침으로 시작한다.

**폭풍 휴식 장면의 종료 조건 확정(2026-09-18 사용자 결정, D08): 장면에 정해진 편지 읽기·대화를 마친 뒤 플레이어가 휴식을 선택하면 다음 게임 내 날로 넘어간다.** 추가 대화·정비는 선택 사항이며 하루 종료의 필수 조건으로 삼지 않는다. 필수 내용을 마쳤다고 자동으로 다음 날로 넘기지 않고 휴식 선택을 기다린다. 장면의 배치와 필수 편지·대화의 구체적인 내용은 후속 서사 설계에서 정한다.

폭풍 장면에서는 오스카가 아버지의 오래된 배달 장부에서 노르드발 주소를 보여주며 “폭풍이 지나가면 북쪽으로 갈 수 있어.”라고 말한다. 이는 북부 지역의 예고이며 마지막 편지의 해금은 3막 진입 때 별도로 안내한다. 셀마 관련 사진·메모 확인은 선택 사항으로 두고 휴식·다음 날 진행의 필수 조건에서 제외한다.

## 8. 성장

기체 해금은 새로운 비행 환경으로 진입하는 사건이다. 3막과 기체의 서사적 연결은 [시놉시스](02.시놉시스.md)에 둔다. 플레이어는 바람 방향 파악, 역풍 회피, 순풍 활용, 상승기류 탐색, 고도 관리, 날씨 변화 대응, 제한된 시야에서의 비행을 익힌다.

**2026-09-18 사용자 결정(D05): 세 기체를 막에 맞춰 순서대로 해금하고, 해금한 기체는 격납고에서 자유롭게 교체한다.**

1막의 전환 사건은 첫 정규 배달을 완료하고 벨로아 우체국으로 귀환한 뒤 시작할 수 있다. 오스카가 산맥 입구까지의 시험 비행을 제안하며, 추가 정규 배달 횟수나 선택 편지 완료를 요구하지 않는다(2026-09-18 사용자 결정). 시험 비행 제안만으로 막이 전환되는 것은 아니며, 아래의 맞바람 경험과 귀환 사건을 거쳐 2막으로 진행한다.

1막에서 2막으로의 전환은 산맥 입구의 강한 맞바람을 경험한 리브가 무리한 비행을 포기하고 벨로아 우체국으로 귀환하는 사건으로 구성한다. 귀환 후 오스카가 장거리 노선과 DH-4를 맡기며 2막에 진입한다(2026-09-18 사용자 결정). 에다를 포함한 선택 편지 완료는 이 전환의 조건이 아니다. 충돌·연료 고갈 후의 D04 복귀와 구분하며, 바람을 읽고 돌아가기로 한 판단을 성장으로 표현한다. 이어서 2막 전환 직후의 폭풍 휴식 장면을 진행한다.

**시험 비행의 귀환 방식(2026-09-18 사용자 결정): 직접 귀환과 간편 귀환을 함께 제공한다.** 직접 귀환을 기본으로 안내하되 간편 귀환도 선택할 수 있게 한다. 직접 귀환은 플레이어가 우체국까지 조종하고, 간편 귀환은 플레이어가 선택하면 짧은 연출로 우체국에 돌아온다. 두 방식 모두 동일하게 오스카의 장거리 노선·DH-4 인계와 2막 전환으로 이어지며, 보상·진행 기록에 차이를 두지 않는다. 이 선택은 산맥 시험 비행 장면의 규칙으로 관리한다.

산맥 입구 300m 전부터 구름이 낮아지고 스카프가 역풍 쪽으로 당겨지며 엔진음이 잠시 낮아진다. 맞바람에 진입하면 화면 아래에 “돌아갈까요?”를 표시한다. 직접 귀환을 고르면 우체국 방향만 안내하고 플레이어가 조종하며, 간편 귀환을 고르면 짧은 연출 뒤 우체국 활주 지점에 도착한다. 선택을 닫으면 직접 귀환 상태로 유지한다.

2막에서 첫 장거리 정규 배달을 완료하고 벨로아 우체국으로 귀환하면 오스카가 아버지의 배달 장부를 통해 마지막 편지의 위치를 알려주고 Mailwing을 맡긴다. 이 안내로 마지막 편지를 해금하며 3막으로 전환한다(2026-09-18 사용자 결정). 니코·마르타·루카스·셀마 등 선택 편지의 완료 여부는 전환 조건에 포함하지 않는다. 장거리 노선의 구체적인 거리와 연료 조건은 후속 실측으로 정한다.

| 해금 시점 | 기체 | 역할 |
|---|---|---|
| 1막 시작 | Curtiss JN-4 Jenny | 느리고 다루기 쉬운 입문 기체 |
| 2막 진입 | de Havilland DH-4 | 적재와 장거리 비행에 유리한 기체 |
| 3막 진입 | Pitcairn Mailwing | 바람을 섬세하게 타고 활공하기 좋은 기체 |

첫 완성판에는 기체 전용 의뢰를 넣지 않는다. 노선의 거리·적재·바람에 맞춰 적합한 기체를 고르도록 한다. 기체별 수치는 [비행·코어 루프](03.비행_코어루프.md)에서 검증하며, 이전 개조·수집·지역 후보는 [제작·연출 참고](P.제작_연출참고.md)에 보관한다.

**기체 개조 범위 확정(2026-09-18 사용자 결정): 첫 완성판은 도장·외형 꾸미기만 제공하고, 비행 성능 개조는 제외한다.** 꾸미기는 도장 색상·스카프 색상·간단한 기체 표식의 세 범주로 구성하고 서로 다른 노선의 첫 배달 완료와 막 진행으로 해금한다(2026-09-18 범주·막 진행 결정, 2026-09-19 배달 해금 기준·노선별 고정 보상 결정). 각 노선과 막에는 미리 정한 꾸미기를 배치하며, 공통 목록에서 보상을 선택하게 하지 않는다. 속도·조종성·적재량·항속·활공 수치를 바꾸지 않으며, 기존 보조 연료탱크·방수 도장·야간 조명처럼 항속 거리나 비행 조건을 바꾸는 기능 개조도 첫 완성판에 적용하지 않는다. 돈·평판 수치와 상점·제작 재료는 사용하지 않는다. 기체 3대의 역할을 유지하며, 세부 꾸미기 목록·개수와 노선별·막별 보상 배치는 후속 설계에서 정한다.

간편 귀환의 사용 범위는 1막 산맥 시험 비행에 한정한다(2026-09-18 사용자 결정). 일반 배달·자유 비행에는 임의로 우체국에 돌아가는 간편 귀환을 제공하지 않으며, 직접 비행하며 경로와 연료를 판단한다. 충돌·연료 고갈 후 안전 지점으로 돌아가는 D04 복귀는 기존 규칙대로 적용한다.

## 9. 하루의 예시

우체국에서 정규 우편을 받고 날씨와 기체 상태를 확인한다. 가까운 강가 마을로 출발해 상승기류를 활용하고 편지를 전달한다. 마을 외곽의 오래된 우편함에서 아버지의 흔적을 발견하면 선택적으로 조사한다. 바뀐 바람에 맞춰 귀환한 뒤 배달 기록과 새 정보를 확인하고, 해금된 꾸미기가 있으면 살펴본다. 이어서 미배달 우편을 살펴본다.

이 예시는 흐름 설명이며 날씨·편지 수·배달 방식을 확정하지 않는다.

## 10. 기능 추가 기준

새 기능이 바람을 읽는 행동, 배달 경험, 느린 여행의 가치 중 하나를 강화하는지 확인한다. 어느 것에도 기여하지 않으면 삭제 후보로 둔다.

성공 여부를 판단할 질문과 구현 범위는 [프로토타입 검증](P.프로토타입검증.md)에서 관리한다.
