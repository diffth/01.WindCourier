# 바람 배달부 (Wind Courier) — 게임물 사용설명서 (공개용)

> 정리일: 2026-10-12 · 상태: 초안 (사용자 검토 전) · 대상 빌드: 1.0.0
> GCRB 등급분류 신청 ④ 첨부문서의 **공개용** 사용설명서. 이야기의 결말과 편지 내용은 [비공개용](ZR.등급분류_사용설명서_비공개용.md)에만 적는다. 근거: [등급분류 신청자료](ZR.등급분류_신청자료.md) 1.3, 공개 안내문 `SourceArt/Release/README_읽어주세요.txt`.

## 1. 게임 소개

| 항목 | 내용 |
|---|---|
| 게임물 이름 | 바람 배달부 (Wind Courier) |
| 제작 | ozs |
| 플랫폼 | PC (Windows 10/11 64비트), Steam 다운로드 |
| 장르 | 비행 어드벤처 |
| 이용 형태 | 혼자 하는 오프라인 게임. 온라인 기능·다른 이용자와의 소통 없음 |
| 결제 | 게임 구매 1회. 게임 안 결제·확률형 아이템 없음 |
| 언어 | 한국어, 영어, 독일어, 프랑스어, 이탈리아어, 스페인어 (자막·화면 글자, 음성 없음) |
| 플레이 시간 | 처음부터 엔딩까지 약 1시간 30분 |

전쟁이 끝난 1920년대 유럽풍의 가상 지역. 열여섯 살 우편 비행사 리브가 작은 복엽기로 철길이 닿지 않는 마을과 마을 사이에 편지를 나릅니다. 플레이어는 바람(스카프·구름·새·상승기류)을 읽으며 날고, 마을 위로 낮게 내려가 우편을 떨어뜨리거나 활주로에 내려 편지를 직접 전합니다.

## 2. 설치와 실행

- Steam 라이브러리에서 "플레이"를 누르거나 `WindCourier.exe`를 실행합니다.
- 처음 켤 때 PC 성능을 한 번 재서 그래픽 품질을 고릅니다. 설정에서 바꿀 수 있습니다.
- 타이틀에서 "시작"(저장이 있으면 "이어하기")을 고릅니다.
- 게임은 영어로 시작합니다. 타이틀·카운터·조작 안내에서 Tab(패드는 View)을 누를 때마다 한국어 → Deutsch → Español → Français → Italiano 순으로 바뀝니다. 설정에서도 고를 수 있습니다.

**시스템 사양**

| 항목 | 최소 (그래픽 "낮음", 1920×1080, 30 fps) | 권장 (그래픽 "높음", 1920×1080, 60 fps) |
|---|---|---|
| 운영체제 | Windows 10 64비트 | Windows 10/11 64비트 |
| 프로세서 | Intel Core i5-7400 / AMD Ryzen 5 1600 | Intel Core i5-10400 / AMD Ryzen 5 3600 |
| 메모리 | 8 GB | 16 GB |
| 그래픽 | NVIDIA GTX 1060 6 GB / AMD RX 580 8 GB (DirectX 12) | NVIDIA RTX 3060 / AMD RX 6600 XT |
| 저장 공간 | 3 GB | 3 GB |

## 3. 조작

키보드와 게임패드(Xbox 배치)를 모두 쓸 수 있습니다. 화면의 키 표기는 마지막으로 쓴 장치에 맞춰 바뀝니다.

**비행**

| 키보드 | 게임패드 | 동작 |
|---|---|---|
| W / S | 왼쪽 스틱 위 / 아래 | 기수 내리기 / 올리기 |
| A / D | 왼쪽 스틱 좌 / 우 | 왼쪽 / 오른쪽으로 돌기 |
| Shift | RT | 출력 보조 — 빨리 오르고 연료를 많이 쓴다 |
| Ctrl | LT | 활공 — 엔진을 끄고 연료를 쓰지 않는다 |
| E | A | 우편 투하 · 착륙 · 편지 전달 · 창 닫기 |
| Esc | Menu | 일시정지 메뉴 |

**우체국 카운터**

| 키보드 | 게임패드 | 동작 |
|---|---|---|
| 1 ~ 7 | 십자키로 고르고 A | 오늘의 노선 고르기 |
| 위 / 아래, L | LB / RB, X | 서랍 편지 고르기 / 싣기 |
| H | Y | 기체 바꾸기 (다른 기체가 열린 뒤부터) |
| R | Y | 하루를 마치고 쉬기 (저장) |
| Tab | View | 언어 바꾸기 |

## 4. 게임 진행

1. **아침 카운터** — 우체국장 오스카에게서 오늘의 노선(최대 7개)을 고르고, 원하면 서랍 속 오래된 편지를 함께 싣습니다.
2. **비행** — 자동으로 이륙한 뒤 조종이 넘어옵니다. 화면 위쪽 안내가 다음 목적지의 방향과 거리를 알려 줍니다.
   - **우편 투하**: 마을 위로 낮게 내려가 안내가 노란색일 때 E(A). 놓쳐도 우편은 남아 다시 접근할 수 있습니다.
   - **착륙 전달**: 활주로에 맞춰 내려가면 착륙 보조가 접지를 돕습니다. 내린 뒤 E(A)로 편지를 전하고 받는 사람의 대답을 읽습니다.
   - **바람 읽기**: 스카프와 구름이 바람의 방향을 보여 줍니다. 구름 아래의 상승기류에 들어가 돌면 연료를 쓰지 않고 오를 수 있습니다.
   - **연료**: 출력 보조는 연료를 많이 쓰고 활공은 쓰지 않습니다. 보급 활주로에 내려 연료를 채울 수 있습니다. 연료가 바닥나면 엔진이 멈추고 활공으로 내려앉습니다.
   - **부딪힘**: 지면이나 나무에 가볍게 스치면 흔들림과 소리만 납니다. 크게 부딪히면 화면이 잠깐 어두워진 뒤 가까운 안전한 곳 상공에서 다시 납니다. 기체가 부서지거나 사람이 다치는 장면은 없습니다.
3. **저녁** — 우체국으로 돌아오면 그날의 배달이 정산되고 짧은 대화가 이어집니다. R(Y)로 쉬면 하루가 저장되고 다음 날이 시작됩니다.
4. 날이 지날수록 해안·호수·산간·북쪽의 새 노선과 기체가 열립니다. 노선을 마치면 기체 도장과 스카프 같은 꾸미기가 생깁니다. 엔딩 뒤에도 열린 노선을 자유롭게 날 수 있습니다.

## 5. 메뉴와 설정

- **타이틀**: 시작(이어하기) · 새로 시작 · 설정 · 크레딧 · 게임 종료
- **일시정지**: 계속 · 조작 안내 · 설정 · 타이틀로 · 게임 종료. 하루는 쉴 때 저장되며, 쉬지 않고 나가면 그날 비행한 것은 남지 않습니다.
- **설정**: 해상도, 화면 모드, 수직 동기화, 그래픽 품질(낮음/중간/높음), 음량(전체·비행기 소리·음악·환경음), 언어, 수채화 효과, 글자 크기, 화면 흔들림, 색각 보정(적색약·녹색약·청색약)

## 6. 저장

- 하루를 마치고 쉴 때 자동으로 저장됩니다.
- 저장 위치: `%LOCALAPPDATA%\WindCourier\Saved` (세이브와 설정)
- 처음부터 다시 하려면 타이틀에서 "새로 시작"을 고릅니다.

## 7. 이용 시 참고

- 폭력·선정적 표현·욕설·도박 요소가 없습니다.
- 이야기 배경은 "전쟁이 끝난 뒤"이며, 주인공의 아버지가 돌아오지 않았다는 사실에서 이야기가 시작됩니다. 전쟁이나 사고 장면은 나오지 않습니다.
- 산맥 고개의 눈보라·강한 바람과 폭풍이 지나가는 날의 장면이 있지만, 갑자기 놀라게 하는 연출은 없습니다.
