# 🍃 바람 배달부 (Wind Courier)

> **"오르는 것은 노동이고, 활공은 보상이다."**  
> 바람을 읽고 기류를 타며, 험난한 하늘을 건너 소중한 편지와 소식을 전하는 비행 배달 게임.

## 🛫 코어 메커니즘 요약

- **마이크로 루프**: `기류 탐색(20초)` ➔ `선회 상승(30초)` ➔ `이탈·활공(90초)` ➔ `고도 소진`
- **설계 원칙**: 상승 1 : 활공 3 (순상승률 = 침하율 × 3)
- **플레이 경험**: 바람을 읽는 관찰과 활공의 자유로움이 주는 감성적인 비행 경험
